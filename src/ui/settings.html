Аккаунт и резервная копия

Локальный аккаунт OTIUM
Защитите профиль паролем, PIN-кодом или секретным словом. С ним можно выгрузить всё — входы в аккаунты, сохранённые пароли, историю, закладки, расширения и настройки — в один зашифрованный файл и восстановить на другом компьютере или после переустановки Windows. Аккаунт хранится только на этом компьютере, никуда не отправляется.
Запомните его: без него файл резервной копии не открыть — восстановить забытый пароль невозможно.
Экспорт профиля
Сохранит входы, пароли, cookies, историю, закладки, расширения и настройки в файл .otium, зашифрованный вашим секретом (Argon2id + XChaCha20-Poly1305). OTIUM перезапустится, вкладки вернутся.
Восстановить из файла
Заменит текущий профиль профилем из файла .otium. Текущий сохранится рядом как резервная копия.

Блокировщик рекламы

OTIUM Shield
Блокирует рекламу, трекеры и счётчики ещё до загрузки — страницы открываются быстрее. Движок adblock-rust (как в Brave)

Расширения

Установить из Chrome Web Store
Откройте страницу расширения в Chrome Web Store, скопируйте адрес и вставьте сюда
Работают расширения на Manifest V3: uBlock Origin Lite, AdGuard, Bitwarden, Dark Reader, переводчики и т. п. Старые MV2-расширения (классический uBlock Origin) Chromium больше не поддерживает.
