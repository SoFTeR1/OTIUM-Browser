# OTIUM

Быстрый, лёгкий и стильный браузер для Windows, написанный на Rust.

Оболочка — собственная (Rust + [tao](https://github.com/tauri-apps/tao) / [wry](https://github.com/tauri-apps/wry)),
страницы рендерит системный движок WebView2 (Chromium), поэтому все сайты работают как в Chrome/Edge,
а сам браузер весит несколько мегабайт и стартует мгновенно.

## Возможности

- **Две раскладки** — боковая панель с вертикальными вкладками или Classic View (вкладки сверху), 6 акцентных тем,
  «плавающая» страница, сворачиваемая панель.
- **OTIUM Shield** — встроенный блокировщик рекламы и трекеров на движке [adblock-rust](https://github.com/brave/adblock-rust)
  (как в Brave): EasyList, EasyPrivacy, RU AdList, фильтры uBlock. Сетевая и косметическая фильтрация,
  счётчик заблокированного, исключения для сайтов.
- **Расширения Chrome** — установка по ссылке из Chrome Web Store или из распакованной папки, кнопка расширений
  с их всплывающими окнами (Manifest V3: uBlock Origin Lite, AdGuard, Bitwarden, Dark Reader…).
- **Умная адресная строка** — подсказки из истории, закладок, открытых вкладок и поисковика;
  Google, Яндекс, DuckDuckGo, Bing, Brave или свой поисковик.
- **История и закладки** (SQLite), загрузки с прогрессом, закреплённые и приватные вкладки, «вернуть закрытую вкладку»,
  индикатор и отключение звука вкладки, масштаб, картинка в картинке, полноэкранное видео.
- **Тёмный режим для всех сайтов** и выбор предпочитаемой темы сайтов.
- **Новая вкладка** с часами и редактируемыми плитками (добавить, изменить, перетащить).
- **Менеджер паролей и автозаполнение** WebView2.
- **Локальный аккаунт и зашифрованная резервная копия** — см. ниже.
- Сессия, положение окна и вкладки восстанавливаются; фоновые вкладки «засыпают» и освобождают память.

## Аккаунт и перенос профиля

В настройках можно создать локальный аккаунт, защищённый паролем, PIN-кодом или секретным словом
(хранится только хеш Argon2id). С ним весь профиль — входы в аккаунты (cookies), сохранённые пароли, история,
закладки, расширения и настройки — выгружается в один файл `.otium`:

- шифрование: ключ из секрета через **Argon2id** (64 МиБ, 3 прохода) → **XChaCha20-Poly1305** потоками по 1 МиБ
  с защитой от обрезки и перестановки блоков;
- Chromium шифрует cookies и пароли мастер-ключом, привязанным к пользователю Windows (DPAPI).
  OTIUM кладёт этот ключ внутрь зашифрованного файла и при восстановлении заново защищает его DPAPI
  нового пользователя — поэтому после переустановки Windows все входы и пароли продолжают работать;
- без секрета файл открыть нельзя; экспорт тоже требует секрет.

На новом компьютере: установить OTIUM → Настройки → Аккаунт → «Восстановить из файла».

## Сборка

Нужны Rust (stable, MSVC) и Windows 10/11 с WebView2 Runtime (в Windows 11 он встроен).

```powershell
cargo run --release          # запустить браузер
.\build.ps1                  # собрать dist\OTIUM-<версия>-setup.exe и portable-версию
cargo test                   # тесты
```

Установщик ставит OTIUM для текущего пользователя (без прав администратора) в
`%LOCALAPPDATA%\Programs\OTIUM`, создаёт ярлыки и пункт в «Приложениях». Профиль лежит в
`%LOCALAPPDATA%\OtiumBrowser`.

## Устройство

| Файл | Что делает |
|---|---|
| `src/main.rs` | окно, вкладки, маршрутизация команд между интерфейсом и Rust |
| `src/native.rs` | COM API WebView2: фильтр запросов, загрузки, полноэкранный режим, звук, расширения, DPAPI |
| `src/shield.rs` | блокировщик рекламы |
| `src/store.rs` | история, закладки, подсказки |
| `src/extensions.rs` | загрузка и распаковка расширений из Chrome Web Store |
| `src/vault.rs` | аккаунт и зашифрованная резервная копия |
| `src/settings.rs` | настройки |
| `src/ui/*` | интерфейс: панель браузера, всплывающие окна, новая вкладка, настройки, история |
| `installer/` | установщик |

Интерфейс браузера — отдельный WebView под вкладками; внутренние страницы (`otium://settings`, `otium://history`…)
отдаются через собственный протокол, и только они могут выполнять привилегированные команды — обычные сайты
этого не могут.

## Горячие клавиши

`Ctrl+T` новая вкладка · `Ctrl+Shift+N` приватная · `Ctrl+W` закрыть · `Ctrl+Shift+T` вернуть закрытую ·
`Ctrl+L` адрес · `Ctrl+D` в закладки · `Ctrl+H` история · `Ctrl+Shift+O` закладки · `Ctrl+J` загрузки ·
`Ctrl+,` настройки · `Ctrl+Tab` / `Ctrl+1…9` вкладки · `Ctrl+Shift+B` панель · `Ctrl +/−/0` масштаб ·
`F11` полный экран · `F12` инструменты разработчика
